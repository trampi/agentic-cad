## 4. Functional & FDM Printability Constraints

1. **Print-Bed Adhesion**: Every printable part must have a flat bottom face resting at `Z_min == 0.0 mm` (`bed_flat == true`).
2. **Support-Free FDM Overhangs**: Unsupported overhangs must remain $\le 45^\circ$ from vertical (or use bridging/chamfers).
3. **Top Surface Planarity**: Where applicable, top faces should be horizontal (`top_normal == [0.0, 0.0, 1.0]`) to avoid stepped slicing artifacts.
4. **Clearances & Tolerances**: Document mating clearances, fastener fit allowances, and print orientation assumptions here.
5. **CAD Exchange**: Clean analytical B-Rep surfaces exported as STEP (`AP214`) for Autodesk Fusion compatibility.

## 5. Verification & Acceptance Criteria

- **Automated Metrics (`build/metrics.json`)**:
  - `base_plate`: `size_x == 60.0`, `size_y == 40.0`, `size_z == 6.0`, `min_z == 0.0`, `bed_flat == true`, `top_planar == true`.
